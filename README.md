# Lab07: A Network from First Principles

## Project Overview

This project predicts the number of bicycles rented during a station-hour for Lakeshore Bike Share.

The objective was to build a neural network from first principles using PyTorch, including:

- data preparation
- a custom Dataset
- DataLoaders
- a neural network written as an nn.Module
- a manually written training loop
- validation and testing
- baseline comparisons
- automated tests

The target variable is:

```text
rentals
```

---

## Dataset

The dataset is generated by `bikes_data.py`.

Features:

| Feature | Description |
|----------|-------------|
| hour | Hour of day (0–23) |
| temperature_c | Temperature in Celsius |
| rain_mm | Rainfall during the hour |
| wind_kph | Wind speed |
| is_weekend | Weekend indicator |
| station_type | downtown, residential, or park |

Target:

```text
rentals
```

Total rows:

```text
6000
```

Dataset split:

| Split | Rows |
|---------|------|
| Train | 3600 |
| Validation | 1200 |
| Test | 1200 |

---

## Data Preparation

The preprocessing pipeline uses:

- StandardScaler for numerical features
- OneHotEncoder for categorical features

The scaler and encoder are fit only on the training set.

The processed dataset contains:

```text
8 features
```

after encoding.

---

## Neural Network Architecture

The model is implemented in `model.py`.

Architecture:

```text
Input (8 features)
        ↓
Linear
        ↓
ReLU
        ↓
Linear
        ↓
ReLU
        ↓
Linear
        ↓
Output (1 value)
```

The output layer uses no activation function because this is a regression problem.

Loss function:

```text
MSELoss
```

Optimizer:

```text
Adam
```

---

## Baselines

Two baseline models were implemented.

### Mean Baseline

Predicts the training-set average for every observation.

### Linear Regression

Implemented using:

```python
sklearn.linear_model.LinearRegression
```

## Main Run

Configuration:

```text
Hidden Size = 32
Learning Rate = 0.001
Epochs = 20
```

Results:

| Model | Validation MAE | Test MAE |
|----------|----------:|----------:|
| Mean Baseline | 10.34 | 10.29 |
| Linear Regression | 9.43 | 9.27 |
| Neural Network | 7.05 | 6.90 |

The neural network outperformed both baseline models.

## Limitations

This dataset is synthetic and generated from predefined statistical relationships.

The model does not account for:

- holidays
- special events
- maintenance activities
- school schedules
- traffic disruptions
- public transit delays

Performance on real-world bike-share systems may differ and would require additional real operational data.
